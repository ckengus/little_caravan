## 변경 절차

사용자 결정이나 구현 검증으로 상태가 바뀌면 관련 명세와 STATUS/ROADMAP을 함께 갱신한다. 날짜, 바뀐 내용, 이유, 대체한 ID를 남긴다. 수치 실험은 provisional로 기록하고 확정 규칙처럼 섞지 않는다.

## 2026-10-29 기술 검증 기록

D008 기본 채택 환경을 Node 24.19.0 + TypeScript 5.9.3 + Vite 7.3.7 + Phaser 3.90.0으로 구현·검증했다. Phaser 3 계열을 유지하며 M1은 런타임 도형으로 기능을 확인한다. D014 전투 기본자세와 D009 최종 합성 방식은 계속 검증 대기이며, 도형 동작을 최종 아트 승인으로 간주하지 않는다. 0.1초 도형 프레임/피해 10/HP 100은 테스트 전용이다.
