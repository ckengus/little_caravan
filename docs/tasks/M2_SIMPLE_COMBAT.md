# M2 작업지시 — 간결한 전투 연출

사용자 채택일: 2026-10-29. 이 지시는 기존 별도 검/손 소켓 필수 M2 작업을 대체한다.

## 목적

주인공의 idle1장과 무기 포함 attack1장을 사용해 실제 테스트 필드에서 더미 공격이 보기 좋게 읽히는지 검증한다. 프레임 추가 생성과 정교한 검술 재현을 우선하지 않는다.

## 구현 범위

1. 최신 main을 확인하고 AGENTS/STATUS/ANIMATION_PIPELINE v0.2를 읽는다. 기존 M1 테스트 기능과 판정 로직을 보존한다.
2. actorView와 상태/위치/피해 계산을 분리한다. 표현은 idle/anticipation/impact/recover 단계로 설정하고 각 단계의 이미지/시간/시각 오프셋을 데이터로 둔다.
3. idle.png와 attack.png는 검·손이 함께 그려진 합성 완료 포즈를 사용한다. 별도 무기 소켓이나 원형 손 마스크를 필수로 적용하지 않는다.
4. 새 승인 아트는 아직 없다. 아트가 없으면 준비된 임시 표시를 사용하며 '간결 연출 시험/임시 아트' 상태를 표시한다. 기존 미승인 M2 포즈는 임시 비교로만 사용할 수 있다. 외형 기준 일러스트 전체를 공격 완료 이미지로 오인하지 않는다.
5. 기존 slash의 타격 이벤트와 attack 자세·검 궤적·더미 섬광/밀려남을 맞춘다. 판정은 Lab에서 한 번, 렌더러는 상태만 표현한다.
6. 짧은 전진은 월드 위치와 별도 visualOffset으로 처리한다. 제자리 베기 후 offset/rotation을 복원한다. dash/knockback의 실제 이동 좌표를 되돌리지 않는다.
7. CC 중단·reset·연속 공격·방향 반전 시 남은 이펙트와 시각 오프셋을 정리한다. 정지/배속/단계 진행 시 모든 효과도 게임 시간을 따른다.
8. 기존 걷기/찌르기/대쉬/CC 버튼은 제거하지 않는다. 미지원 자세는 임시 대체 표시를 하고 완성으로 취급하지 않는다.
9. 장비 수치/외형 ID 분리는 유지하되 첫 버전은 공격 그림의 기본 검 외형 고정을 허용한다. 무기2종 교체는 인수 조건에서 제외한다.
10. 효과음은 사용 가능한 적법한 리소스가 있을 때만 추가하며 없으면 시각 확인을 먼저 진행한다. 화면 흔들림/히트스톱은 필수가 아니다.

## 완료 기준

- 기존 빌드·타입 검사·테스트가 통과하고 기존 M1 조작이 유지된다.
- 실제 작은 화면에서 타격 자세·궤적·더미 반응이 동기화된다.
- 공격 종료/CC/reset 뒤 시각 offset이 남지 않는다. 좌우 모두 확인한다.
- 임시 아트와 승인 상태를 명확히 표시한다. 새 아트 부재는 구체적으로 기록한다.
- 배포된 테스트 주소에서 사용자에게 더미 공격 장면을 확인받는다. GIF나 정지 시트만으로 시각 승인을 완료 처리하지 않는다.
- 변경사항·실행한 검증·배포 여부·누락 아트를 STATUS/ROADMAP에 기록한다.

## 전달해야 할 결과
