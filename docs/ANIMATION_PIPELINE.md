# 아트·전투 연출 규격

v0.2 / 2026-10-29 / 현재 기준: 간결한 전투 연출

## 1. 현재 결정

사용자는 정교한 양손검 자세의 반복 실험을 중단하고, **대기 1장 + 무기와 손이 함께 그려진 공격 1장 + 짧은 전진·검 궤적·적 반응** 방식으로 전환했다. 거래·상단 성장이 중심이므로 정확한 검술보다 작은 화면에서 공격과 피격이 잘 읽히는 것이 목표다.

기존 다자세·별도 검·손 소켓 소스 assets/art/source/hero/m2-v1/은 미승인 실험으로 보존한다. 사용자에게 자세가 여전히 어색하다는 피드백을 받았으므로 정식 승인 자산이나 현재 필수 구현으로 간주하지 않는다. 파일을 삭제하지 않으며 신규 아트 방향을 맞추기 위해 이 소켓 구조를 더 정교하게 만드는 작업은 우선 중단한다.

외형 정본: [일행 PNG](../assets/art/references/little-caravan-party-v1.png). 주인공/궁수/흰 강아지/고양이의 확정 외형과 색상은 유지한다.

## 2. 주인공 최소 리소스

- hero-idle.png: 양손검을 잡고 서 있는 온전한 전신 그림 1장.
- hero-attack.png: 검과 두 손이 올바르게 함께 그려진 명확한 타격 자세 1장. 몸/무기를 재합성할 필요 없는 완성 포즈를 우선한다.
- 두 그림은 같은 발 기준점과 표시 비율을 갖춘다. 투명 PNG, 기본 방향은 오른쪽.
- manifest: 이미지 경로, 발 원점, 표시 크기, 시각 단계, 타격 시점과 효과 설정. GIF는 확인용이며 런타임 원본을 대체하지 않는다.
- 헤어/복장/무기가 그림에 합쳐진 상태를 허용한다. 현재 단계에서 부위별로 모두 분리할 필요 없다.

새 2장 소스는 아직 제작/승인되지 않았다. 코덱스는 화면·효과 구현은 진행하되 임시 실루엣을 정식 아트로 보고하지 않는다. 기존 미승인 포즈를 쓰면 임시 비교용임을 명시하고 새 외형 승인처럼 취급하지 않는다.

## 3. 공격 연출

| 단계 | 화면 표현 |
| --- | --- |
| 대기 | 같은 idle 원본, 발 원점은 바닥 고정. 1~2% 내외 작은 상체 느낌의 변형/짧은 수직 변화로 호흡. 발이 뜨거나 과장되면 정지 그림으로 먼저 검증 |
| 준비 | idle 자세를 짧게 유지하며 아주 작은 뒤로 당김/기울임을 선택 적용 |
| 타격 | attack 자세를 짧게 표시, 전방 이동 보정과 검 궤적. 실제 피해 이벤트와 적 섬광·밀려남을 동기화 |
| 복귀 | 동일 idle 원본으로 전환하고 시각 오프셋/회전을 원상 복구 |

몸 전체 변형은 보조 연출로 허용하지만 공격을 모두 대체하지 않는다. 핵심 타격 그림은 별도로 둔다. 중간 그림을 여러 장 추가하는 것은 첫 검증 이후 선택사항이다.

시작용 예시: 전체 공격 0.45~0.65초, 타격 자세 0.08~0.14초, 시각 전진 6~12px 정도. 이는 화면 좌표/현재 스케일에 따라 조절할 임시 범위이지 확정 밸런스가 아니다. 현재 Lab의 공격 주기/판정/테스트를 먼저 보존하고 시각 단계만 연결하는 편이 안전하다.

전투 이동 위치와 공격의 작은 시각 오프셋을 분리한다. 제자리 베기는 공격 후 발 원점으로 돌아오며, 실제 dash/knockback은 이동한 월드 위치를 유지한다. 좌우 반전은 그림·이펙트·판정 방향에 함께 적용한다.

## 4. 이펙트와 반응

- 단순한 검 궤적 1개와 작은 적 타격 섬광을 우선한다. 캐릭터·더미·판정이 계속 보이게 한다.
- 짧은 적 밀려남을 사용하며 경계·사거리에 영향을 주는 실제 이동과 시각 흔들림을 구분한다.
- 효과음은 사용할 수 있는 직접 제작/사용 허용 리소스가 있을 때만 추가한다. 없으면 시각 검증을 진행한다. 음소거와 사용자 입력 후 활성화가 필요하다.
- 화면 흔들림·히트스톱은 기본 필수에서 제외한다. 추가 시 정지/배속/타격 이벤트를 깨뜨리지 않아야 한다.
- 공격 하나의 피해는 기존 상태 로직에서 한 번만 발생한다. 시각 효과 종료 시점에 별도 피해를 다시 넣지 않는다.

## 5. 장비·커스텀 범위 조정

능력치용 장비 데이터와 외형 리소스 ID를 분리해 장래 교체 구조는 유지한다. 다만 **별도 무기 2종의 양손 소켓 합성 성공을 M2의 필수 완료 조건에서 제외**한다.

첫 구현은 idle/attack에 기본 검이 함께 그려진 외형을 사용한다. 장비를 바꿔도 공격 그림의 무기가 자동으로 바뀌지 않는 제한을 문서에 기록한다. 모든 자세에서 다른 검을 정확히 반영하는 기능은 이후 무기별 포즈 세트 또는 검증된 분리 방식으로 별도 진행한다. 이 제한을 숨기고 커스텀 완료라고 보고하지 않는다.

## 6. 나머지 행동과 일행

걷기·대쉬·경직·넘어짐은 기존 상태 로직과 테스트 버튼을 유지한다. 우선 단순 이동/기울임/반동/기상 복귀로 표현하고, 필요한 특수 자세만 나중에 추가한다. 표현하지 못한 동작은 임시임을 표시한다.

주인공의 더미 공격 장면을 먼저 사용자에게 확인받고 다음으로 확대한다.
- 궁수: 대기/발사 자세 + 화살과 적 피격.
- 강아지 마법사: 대기/시전 자세 + 마법탄·폭발.
- 고양이 기술자: 대기/투척 자세 + 폭탄 궤적·폭발.

## 7. 검수 기준

실제 작은 게임 표시 크기에서 다음을 확인한다.
1. 대기와 공격이 구분되고 손·무기의 겹침이 한 그림 안에서 자연스럽다.
2. 타격 자세와 피해·적 반응이 같은 순간 발생한다.
3. 모든 정상 종료·CC 중단·초기화 후 idle과 시각 오프셋이 복원된다.
4. 좌우·배속·일시정지·한 프레임 진행·자동 접근/공격이 기존 기능과 함께 작동한다.
5. 이미지 잘림·흰 배경·깨진 경로가 없으며 이펙트가 과도하지 않다.
6. 자동 검증 성공과 사용자 시각 승인, 실제 휴대폰 검증을 따로 기록한다.

이 문서의 v0.2가 이전 별도 무기 소켓 필수·다자세 제작 규격을 대체한다.
