# 프로젝트 기획서

버전 v0.1 / 기준일 2026-10-29 / 현재 단계 M1 로컬 구현·검증 / 배포 대기

## 1. 목적과 게임 정체성

Little Caravan은 4명의 전 용병 동료가 새 상단을 창설해 지역을 여행하는 1인 제작 2D 방치형 거래·모험 게임이다. 물건을 사고, 사용할 장비를 고르고, 남는 물건을 좋은 시세에 팔아 상단을 성장시키는 경험이 중심이다. 자동 전투는 일행의 역할과 성장 결과를 보여주는 콘텐츠이며 정교한 수동 액션 게임 자체가 최우선 목표는 아니다.

핵심 순환: 손님/물품 확인 → 구매 또는 패스 → 장비 착용 또는 창고 보관 → 자동 탐험 → 전리품과 성장 → 마을 시세 비교·매각 → 슬롯 강화 → 다음 거래·탐험.

## 2. 최종 결과물의 두 단계

### A. 우선 도달할 플레이 가능한 MVP

- PC와 안드로이드 모바일 브라우저에서 링크로 실행한다. 모바일 세로 우선, PC는 편하게 테스트할 수 있도록 배치한다.
- 주인공·궁수·강아지 마법사·고양이 기술자와 마차가 등장한다.
- 알아보기 쉬운 대기·이동·공격과 역할별 대표 스킬, 피격 반응, 투사체·타격 이펙트를 제공한다.
- 구매→보관→착용→탐험→매각→슬롯 강화의 핵심 순환을 연결한다.
- 기본 스테이지 진행, 마차 체력·실패·보수·재도전, 명성·거래 성장, 마을별 시세를 제공한다.
- 로컬 저장, 버전 있는 저장 데이터 내보내기/불러오기, 미접속 경과시간 계산을 제공한다.
- 웹 자동 배포, 게임 데이터와 아트 원본, 적용 설명·검증 방법을 저장소에 유지한다.
- 캐릭터 테스트 필드는 정식 게임과 별도로 계속 접근 가능하다.

### B. 후속 Android 검증판

웹 MVP 이후 Capacitor 등으로 같은 웹 게임을 감싼 APK를 클라우드에서 빌드하고 사용자가 휴대폰에 설치·테스트한다. APK 생성 성공과 제품 품질 검수는 별개다. 상용 출시에는 저장·성능·지원기기·라이선스·배포 준비가 추가로 필요하다. 스토어 출시나 수익은 현재 완료 목표로 보장하지 않는다.

현재 Unity/Godot 재제작은 범위 밖이다. 나중에 필요하면 기술 검증과 별도 결정을 거친다.

## 3. 확정된 일행과 아트 방향

| 캐릭터 | 역할 | 외형 기준 |
| --- | --- | --- |
| 주인공 | 양손검 근접 전투·대장 | 선택 A안, 갈색 머리·청록 스카프·갈색 가죽옷 |
| 궁수 | 활 원거리 공격 | 선택 A안, 금발 포니테일·빨간 리본·레드 계열 의상 |
| 강아지 마법사 | 마법 원거리·제어 효과 | 흰 복슬복슬한 강아지 B안, 둥근 안경·파란 모자/옷, 모자에 가려지는 귀는 숨기고 반대 귀만 표시 |
| 고양이 기술자 | 폭탄·수리 등 기술 지원 | 선택 A안, 주황/크림 털·머리 고글·작업복·렌치·폭탄 |

외형 정본: ../assets/art/references/little-caravan-party-v1.png (문서 기준 실제 링크는 아래 참고).

인게임은 굵은 외곽선·큰 색 덩어리·작은 몸과 큰 머리의 간결한 2D 그래픽이다. 참고 게임 Animal Busters의 작은 화면 가독성과 동작·효과 조합을 품질 방향으로 삼되 고유 디자인을 만든다. 과도한 일러스트 디테일과 부드러운 움직임은 필요하지 않다. 적은 프레임이어도 자세 변화·무게중심·타격 순간은 읽혀야 한다.

타이틀/메인 일러스트와 인게임 리소스는 구분한다. 현재 참고 PNG에 보이는 공격 포즈가 공통 전투 대기 자세까지 확정한 것은 아니다.

## 4. 기존 시제품에서 이어갈 항목과 검증 경계

기존 웹 시제품 주소: https://wandering-caravan-dhm.gentlealder15.chatgpt.site/

이 사이트는 이전 실험 참고용이며 현재 GitHub에 소스가 들어온 상태가 아니다. 공개 링크나 화면만으로 코드·세부 계산·밸런스를 확보했다고 간주하지 않는다. 소스를 전달받으면 별도 검토 후 유용한 계산·데이터를 활용하며, 원본을 통째로 덮어쓰지 않는다.

기존 시제품/논의에는 다음 규칙이 있으나, 새 구현의 **초기 기준 후보**로 보고 M5 전에 계산식·데이터·예외를 재검증한다.

- 마을 12시간 교체, 6시간 전 예고와 개발용 시간 이동.
- 실패 후 약 3초 보수 및 직전 스테이지 재도전. 최초 스테이지 경계는 별도 정의.
- 일행 개별 체력보다 마차 체력을 중심으로 한 전투. 아군 CC 표현과 마차 피해는 별도 처리.
- 손님 대기열과 구매/패스, 창고, 장비 비교, 착용, 슬롯 강화, 명성·손님 티어, 마을별 가격.
- 기존 기본형 실험은 캐릭터 무기 슬롯과 마차 장갑·차체·총포 슬롯을 사용했다. 최종 슬롯 수와 수치는 미정.
- 상점·우편은 실서비스보다 준비 중/모의 화면부터 검토한다.

위 항목의 정확한 가격식, 보상, 성장곡선, 스킬·쿨다운, 창고 수량, 실패 손실은 확정 데이터가 아니다. 테스트 숫자는 data에 두고 provisional임을 표시한다.

## 5. 이번에 바로 만들 것

첫 산출물은 정식 UI가 아닌 **캐릭터 동작 테스트 필드**다. 평평한 바닥, 주인공, 더미 적, 수동 동작 버튼, 자동 접근·공격, 배속·프레임 확인 기능을 가진다. 상세 인수 기준은 ROADMAP의 M1/M2를 따른다.

기능 구현과 아트 시각 승인을 분리한다. 테스트 필드는 임시 아트로 먼저 만들고, 주인공의 대기·베기·복귀와 별도 무기의 그립을 먼저 완성한 후 4명으로 확장한다.

## 6. 현재 제외 범위

실결제·계정/서버·클라우드 동기화·멀티플레이·데이터 변조 방지·코스튬 대량 제작·모든 동작 고프레임 제작은 현재 범위 밖이다. 숨김/종료된 브라우저에서 전투 실행을 보장하지 않는다. 필요 시 복귀 시점의 경과시간 계산으로 처리한다.

무기·헤어·복장·수염·장식 교체의 확장성을 고려하되 지금 전부 제작하지 않는다. 별도 무기와 두 번째 시험용 검으로 먼저 교체 구조를 검증한다.
