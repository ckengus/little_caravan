## M0 — 공유 기반

산출물: 기획서·개발환경·아트 규격·로드맵·상태·결정 기록·AGENTS와 확정 외형 이미지. 실행 코드나 테스트 URL이 생성됐다는 뜻은 아니다.

## M1 — 웹 테스트 필드

### 작업

- Vite/TypeScript/Phaser 환경, 잠금 파일, 실행 명령, 기본 CI.
- 평평한 테스트 필드·주인공 임시 표시·바닥 기준선·조작 패널.
- 수동/자동 모드 전환, 더미 투입·제거·초기화.
- 버튼: 대기, 좌로 걷기, 우로 걷기, 베기, 찌르기, 대쉬, 돌진 베기, 경직, 넉백/넘어짐/기상.
- 걷기는 누르는 동안 이동하고 떼기/취소/포커스 상실 시 정지.
- 없는 동작은 임시 상태/실루엣으로 표시하고 미완성 아트임을 알린다.
- 0.25/0.5/1배, 일시정지, 한 프레임 진행, 현재 상태/프레임, 원점·무기/그립·공격 범위 표시.
- 적 투입: 더미 생성→접근→사거리 정지→자동 공격. 더미는 체력·피격 색 변화·작은 밀려남. 피해 수치는 임시.
- GitHub Pages 자동 배포 설정 및 PC/모바일 레이아웃 확인.

### 완료 기준

- npm ci/typecheck/test/build가 실제 실행 가능하고 결과를 기록한다.
- 테스트 페이지가 열리고 버튼·입력 취소·초기화가 작동한다.
- 더미 접근·공격당 1회 피해·CC 중단의 기본 검증이 통과한다.
- 일시정지에서 이동/공격 시간이 멈추고 한 프레임 진행은 선택 애니메이션의 다음 프레임 경계까지 모든 게임 시간을 함께 진행한다. 이벤트가 유실·중복되지 않는다.
- 아트 누락·임시 상태가 표시된다. 전체 그림 흔들기를 정식 베기로 통과시키지 않는다.
- 실제 웹 배포 성공과 URL 확인까지 목표로 한다. 외부 설정이 막히면 코드 완료와 배포 차단을 별도 기록하고 M1 전체 완료로 표기하지 않는다.

## M2 — 간결한 주인공 전투 연출

기준은 [ANIMATION_PIPELINE v0.2](ANIMATION_PIPELINE.md)와 [다음 작업지시](tasks/M2_SIMPLE_COMBAT.md)다.

- idle1장과 무기/손 포함 attack1장을 준비한다. 기존 소켓 합성 실험은 미승인으로 보존한다.
- 실제 테스트 필드에 짧은 시각 전진·검 궤적·적 섬광/반동을 연결한다.
- 정상 종료/CC 중단/reset 후 같은 idle과 원래 시각 오프셋으로 복귀한다.
- 별도 검2종 교체와 정교한 다자세 리깅은 현재 완료 조건이 아니다.
- 좌우·배속·일시정지·단계 진행·더미 자동 전투를 검증하고 사용자가 작은 화면의 전투 장면을 확인한다.
- 아트가 없으면 임시 상태를 표시하고 연출 파이프라인은 구현한다. 기술 완료와 시각 승인은 구분한다.

## M3 — 주인공 이동·피격 표현 확장

M1의 걷기/찌르기/대쉬/돌진/경직/넉백 상태를 유지하며 단순 이동·반동·필요한 특수 자세로 연출한다. 모든 상태에 정교한 전신 프레임을 그리는 작업은 필수가 아니다. CC 취소, 도착 위치, 좌우, 필드 경계, 복귀·reset을 확인한다. 미완성 시각 표현은 임시라고 표시한다.

## M4 — 4인 전투 샘플

궁수의 발사, 흰 강아지 마법사의 시전, 고양이 기술자의 폭탄 투척부터 만든다. 4명·마차·기본 적 1~2종·배경 1종을 배치한다. 각 대표 스킬 1개는 회전참/멀티샷/폭발 제어마법/폭탄·수리 등 기존 아이디어를 후보로 삼고 정확한 효과는 데이터 설계 후 확정한다.

완료 기준: 공격 종류가 작은 화면에서 구분되고 투사체와 피해 시점이 맞는다. 전투 30초 내외를 실제 재생해 겹침·이펙트 과다·효과음·마차 피격과 실패를 검수한다. 기능 검증과 사용자 시각 승인은 별도다. 단순 샘플 통과가 모든 스킬 제작 완료는 아니다.

## M5 — 거래·성장 MVP

기존 시제품 소스/규칙을 확보할 수 있으면 검토하고, 없으면 미정값을 명시한 최소 데이터부터 설계한다. 구매/패스→창고→비교/착용→자동 탐험→시세 매각→슬롯 강화와 명성 성장, 마을 교체를 연결한다. 저장 버전·내보내기/불러오기·미접속 시간 계산을 추가한다.

완료 기준: 사용자가 핵심 순환을 반복할 수 있고 자금·물품·장비가 중복/소실되지 않는다. 시간 가속으로 마을 전환/실패/재접속을 확인한다. 가격·강화·전투 수치는 provisional에서 실제 플레이 검증값으로 단계적으로 바꾼다.

## M6 — 모바일·APK

모바일 실기기에서 터치·회전·복귀·저장·성능을 검증한다. 이후 Android wrapper와 클라우드 debug APK 빌드를 추가한다. 다운로드한 APK의 설치·실행을 사용자가 확인한다. 실결제·서버·스토어 출시는 별도 기획이므로 묶어서 완료했다고 보고하지 않는다.

## 작업 단위

한 작업은 눈으로 확인할 기능과 명확한 검증 범위를 가진다. 예: '주인공 베기 그립 수정', '더미 접근 후 공격 1회 연결'. 매 작업에 변경 파일·테스트 결과·실제 확인 방법·남은 아트를 기록한다. 큰 단계가 끝나기 전에도 작은 작동 결과를 공유한다.
