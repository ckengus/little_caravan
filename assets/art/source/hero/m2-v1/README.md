# 주인공 M2 아트 v1 — 시각 검수 대기

[적용용 PNG/JSON 묶음](./hero-m2-runtime-v1.zip)

## 포함 범위

- 무기 없는 주인공 전신 6자세: ready / windup / impact / followthrough / recover / inhale.
- 별도 silver / teal 양손검 2종.
- 손 전경 패치, 각 자세의 앞손/뒷손 소켓, 발 원점, 배치 좌표, 레이어 순서.
- hero.json의 idle/slash 재생시간과 타격 프레임.

정식 외형에 기반한 게임용 소스 초안이며 **사용자 시각 미승인, 테스트 필드 미적용** 상태다. 기존 확정 일행 PNG를 교체하지 않는다. 걷기/찌르기/돌진/CC 아트와 헤어/의상 분리는 미포함이다.

## Codex 다음 작업

1. ZIP을 읽고 body/hands/weapons와 hero.json을 작업 폴더에 풀어 실제 파일을 확인한다. 경로 기준은 hero.json이 위치한 디렉터리다.
2. source 이미지와 JSON을 보존하면서 public/game-assets/hero-m2-v1/ 등 런타임 경로를 정한다. 테스트 필드에 M1 임시 도형과 M2 아트의 선택 옵션을 둘 수 있다.
3. 이미지 position은 1024×1024 가상 캔버스의 좌상단 좌표다. 발 원점 [430,820]을 월드 위치에 맞춘다.
4. 무기 rearGrip/frontGrip 두 점이 자세의 rearGrip/frontGrip 두 점에 일치하도록 동일 비율 회전/이동/크기 변환한다. 단일 손 피벗만 사용하는 방식으로 바꾸지 않는다.
5. body → weapon → foregroundHands 순서로 합성한다. 지금 제공한 손 패치는 시험 마스크다. 무기가 팔에 잘못 가려지거나 가드가 손을 침범하면 자세별 패치를 정리하고 검수한다.
6. 좌우 반전은 발 원점 기준으로 body/weapon/hands/두 소켓을 함께 반전한다.
7. slash 6프레임의 순서는 ready→windup→impact→followthrough→recover→ready이고 타격 인덱스는2다. 첫/끝 ready 원본은 동일하다. 현재 상태 모델의 재생시간/타격 시점과 manifest의 시간은 어댑터에서 일치시켜야 한다. 데이터 변경 없이 애니메이션만 먼저 바꿔 피해 시점이 어긋나지 않게 한다.
8. 제공되지 않은 행동은 임시 도형 유지 또는 명시적 기본자세 대체로 표시한다. 해당 동작이 완성됐다고 보고하지 않는다.
9. 실제 작은 크기·좌우·느린 재생·두 검 교체를 검증하고 사용자 시각 검수 전까지 M2 완료로 표시하지 않는다.

## 제작/검증

2026-10-29 내장 imagegen으로 생성한 아트를 PNG 분리·좌표 측정·두 손 소켓 합성으로 준비했다. ZIP은 전송용 인덱스 PNG를 사용하고 원본 크기·좌표는 유지했다. 완전판 생성 원본과 GIF는 이번 대화에 제공했다.

알파, 가상 캔버스 경계, 첫/끝 ready 일치와 두 검의 소켓 합성은 로컬 확인했다. 실제 Phaser 적용·브라우저·모바일·사용자 최종 승인 검증은 아직 하지 않았다. 프레임 간 체형 변화와 그립/회수 동작은 추가 시각 검수가 필요하다.
