# M2 간결 연출 임시 포즈

2026-10-29 직접 작성한 기하 도형 SVG 2장. 상태: **temporary-unapproved**. 확정 일행 일러스트나 보관된 m2-v1 ZIP에서 추출한 아트가 아니다. 손과 검은 각 SVG 안에 포함하며 별도 소켓 합성은 하지 않는다.

- 캔버스: 256×256, 투명 배경, 오른쪽 기본 방향.
- 발 원점: (128,234), Phaser origin=(0.5,0.9140625).
- 표시: 캔버스 높이 160 월드 px, scale=0.625, 좌우 반전은 발 원점 기준.
- idle / attack 두 그림은 동일 캔버스·발 원점. 준비/복귀는 같은 idle 파일을 재사용한다.
- `src/data/hero.ts`가 경로·원점·표시 크기·단계별 포즈/offset/rotation·타격 유지시간·효과를 정의한다.
- Vite는 SVG를 별도 해시 파일로 출력한다. Phaser SVG 로더는 인라인 percent-encoded data URI를 올바르게 처리하지 못하므로 `assetsInlineLimit: 0`을 유지한다.

## 교체할 승인 PNG 계약

필요한 파일은 `hero-idle.png`, `hero-attack.png` 두 장이다. 각각 **256×256 RGBA 투명 배경**, 발 기준점 **(128,234)**, 오른쪽을 향하는 온전한 전신과 검/두 손 포함 포즈. 도형과 동일 비율로 맞추되 모든 그림·검·stroke는 캔버스 내부에 보존한다. 표시 높이는 160px, 발은 ground=330에 정렬한다. 좌우 공통 발 원점과 동일 캐릭터 비율을 유지한다.

PNG 적용 시 hero.ts 이미지 경로를 바꾸고 scene preload를 SVG에서 image 로더로 변경한 뒤 알파·잘림·좌우·작은 화면을 재검증한다. 이 단계에서는 자동 포맷 전환이나 완성 아트 보유를 주장하지 않는다. 현재 스키마의 equipment/appearance는 구분된 식별 데이터이며 실제 장비 교체 UI/시스템은 없다. 기본 검 외형 고정이며 능력치 변경만으로 그림 속 검은 바뀌지 않는다.
